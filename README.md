# Song Collection

## 查歌 | 自义定列表 工具

写这个工具其实只是给自己用的.jpg

这是一个支持多种查分器的成绩管理工具。有则更加强大的搜索功能、支持自义定列表，可以对成绩进行整理，并且附带统计。

### 平台

现在工具有两个平台：Web和Android，其中Android使用capacitorjs进行转译。

### 搜索

搜索使用flexsearch.js 可以通过、曲名、别名、谱师、曲师。它们不区分大小写并且可以通过直接拼音的方式进行搜索。其次，使用标签过滤可以快速搜索你需要限制范围的曲目。同时你还可以将搜索结果一键导入到合集当中。

### 歌曲卡片

在这里可以轻松复制 歌曲id、别名、曲名和曲师。也能看到所在版本和区域与分类。

### 成绩卡片

在使用支持保存“游玩次数"的查分器的数据源时，可以显示其游玩次数。

### 合集

在这里可以分门别类的管理你的成绩，支持排序、统计、搜索。例如你可以创建一个13分数列表，查看你的13等级牌进度，也可以挑出一些需要长期攻克的成绩放到独立的列表当中。
